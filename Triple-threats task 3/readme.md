# TuneWave 
### A Smart Music Player Powered by Data Structures & Algorithms

TuneWave is a modern, responsive music-player dashboard that demonstrates how fundamental **Data Structures and Algorithms (DSA)** can power real-world application features. Built with HTML, CSS, and vanilla JavaScript, it combines an immersive user interface with interactive algorithm visualizations.

##  Key Features

- **Playlist Management:** Doubly linked list and hash map for efficient song navigation and ID-based lookup.
- **Queue & Listening History:** FIFO queue for upcoming songs and a capped stack for playback history.
- **Intelligent Song Search:** Binary Search Tree (BST) with prefix-based title searching.
- **Artist Discovery:** Graph-based recommendations identifying artists exactly two connections away.
- **Interactive Dashboard:** Live statistics, execution logs, data-structure visualizations, and synchronized player controls.
- **Modern UI:** Responsive design, neon aesthetics, dark/light themes, and popup navigation.

##  Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser, or launch it using VS Code Live Server.
3. Explore the playlist, queue, search, and artist discovery features.

**No frameworks, dependencies, or backend setup required.**

##  Project Highlights

TuneWave transforms theoretical DSA concepts into interactive demonstrations, connecting algorithmic efficiency with practical user experiences. It showcases modular data-structure implementations, synchronized UI updates, and edge-case handling in a self-contained web application.
