# ReliefHub — Flood Relief Coordination System

ReliefHub is a web-based platform that helps coordinate flood relief operations by managing relief camps, essential supplies, camp needs, dispatches, donations, and volunteers in one place.

### Key Features
- **Camp Management:** Track camps, districts, capacity, and families sheltered.
- **Inventory Management:** Monitor available stock and low-stock items.
- **Needs Management:** Track camp requirements, priorities, and fulfilment progress.
- **Dispatch Tracking:** Manage supply distribution and dispatch status.
- **Donations:** Record cash and in-kind contributions.
- **Volunteer Management:** Register volunteers and assign them to camps.
- **Dashboard:** View key statistics, critical resource gaps, low-stock alerts, and recent dispatches.
- **Role-Based Access:** Separate access for Relief Coordinators (Admin) and Field Volunteers.

### Tech Stack
React, Vite, Tailwind CSS, Node.js-based JSON Server mock API, and Axios.

### Getting Started
1. Install dependencies: `npm install`
2. Seed the demo data: `npm run seed`
3. Start the application and mock API: `npm run dev:all`
4. Open `http://localhost:5173` in your browser.

**Purpose:** To improve visibility, resource allocation, and coordination during flood relief operations.
