# KisanMandi

Crop prices and marketplace for Sindh.

## Setup

1. Install dependencies:
```bash
flutter pub get
```

2. Start the mock backend:
```bash
cd mock_api
npx json-server@0.17.4 --watch db.json --port 3000
```

3. Run the app:
```bash
flutter run -d chrome
```

## Testing

```bash
flutter test
```
