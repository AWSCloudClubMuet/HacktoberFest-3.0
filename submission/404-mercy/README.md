# 404 MERCY — KisanMandi Hackathon Submission

This directory contains the final submission for **KisanMandi: Crop Prices & Produce Marketplace** by **Team 404 MERCY**.

The complete project source code, database, seed generator, automated tests, and configuration reside in [`kisanmandi/`](./kisanmandi).

## Quick Run

```bash
cd kisanmandi
npm install
npm run seed
npm run api     # Starts JSON Server on http://localhost:3001
npm run dev     # Starts Frontend on http://localhost:5173
```

To run the full 41-check automated verification suite:
```bash
cd kisanmandi
node verify.js
```

Refer to [`kisanmandi/README.md`](./kisanmandi/README.md) for full project documentation and deployment instructions.
