# HelpDeskNet-50K — Noisy Label Analysis and Review Strategy

**HacktoberFest 3.0 — AI/ML Track**

**Official Task:** [GitHub Issue #9 — HelpDeskNet-50K](https://github.com/AWSCloudClubMuet/HacktoberFest-3.0/issues/9)

## Project Overview

HelpDeskNet-50K is a fictional customer-support ticket classification scenario containing 50,000 tickets across six categories: Billing, Refund, Technical, Account Access, Shipping, and Other.

The classifier reports 82% accuracy, but an expert audit identifies disagreements between crowdworker labels and expert judgments.

This project investigates annotation noise, analyzes systematic labeling errors, estimates the effect of noisy evaluation labels, and proposes strategies for targeted expert review and more reliable model training.

The implementation uses Python and provides reproducible statistical analysis, visualizations, synthetic review-selection demonstrations, and automated tests.

**Important:** The original task provides aggregate statistics rather than actual ticket-level records. Synthetic datasets and simulated model predictions are used only to demonstrate the selection workflow. No real HelpDeskNet classifier was trained or evaluated.

## Implemented Milestones

### Milestone 1 — Quantify Label Noise

Calculated the observed audit disagreement rate, Wilson confidence interval, population-weighted disagreement estimate, and statistical significance of the difference between annotator tiers.

Key findings:

- Observed audit disagreement: 15%
- Tier A disagreement: 6.67%
- Tier B disagreement: 21.82%
- Two-proportion z-statistic: approximately -4.222
- Two-sided p-value: approximately 0.0000242

### Milestone 2 — Characterize Label Noise

Analyzed category confusion patterns from the provided expert audit.

The most common confusion is Billing and Refund, accounting for 26 out of 60 disagreements.

The project generates a visualization showing major confusion pairs and discusses possible causes and improvements to annotation guidelines.

### Milestone 3 — Accuracy Ceiling

Estimated the classifier's underlying accuracy using a simplified uniform independent label-noise model.

- Reported accuracy: 82%
- Assumed label noise: 15%
- Theoretical corrected accuracy: approximately 96.34%

This is a conditional mathematical estimate, not experimentally measured model accuracy.

### Milestone 4 — Finding Potentially Incorrect Labels

Implemented a Python review-selection demonstration.

The program generates 45,000 synthetic ticket records and selects 2,000 unique tickets for a proposed expert-review queue.

The review allocation is:

| Selection strategy | Tickets |
|---|---:|
| High-confidence model-label disagreements | 1,000 |
| Known confusion-pair candidates | 500 |
| Uncertain or rare-category cases | 300 |
| Random control group | 200 |
| **Total** | **2,000** |

The algorithm excludes duplicate IDs and does not expose synthetic true labels in the exported review queue.

The predictions and confidence values are simulated, not generated by a trained model.

### Milestone 5 — Noise-Robust Training and Reliable Evaluation

Proposed two methods for reducing the impact of noisy training labels:

1. **Label smoothing:** Reduces excessive confidence in training labels. Implemented a NumPy demonstration comparing ordinary and smoothed targets and cross-entropy losses.
2. **Co-teaching:** Uses two models to exchange selected low-loss examples. Proposed as a future training experiment; not implemented.

The report also describes an independent expert-labeled test set and recommends accuracy, macro F1, class-wise precision and recall, and confusion matrices for evaluation.

## How to Run the Project

Open VS Code and navigate to the `helpdesknet-50k` directory.

### 1. Install Dependencies

Use Python 3.11 or newer and an activated virtual environment.

```powershell
python -m pip install -r requirements.txt
```

### 2. Run Milestones 1–3

```powershell
python -m src.analysis
```

Generates statistical calculations and visualizations.

### 3. Run Milestone 4

```powershell
python -m src.review_strategy
```

Generates 45,000 synthetic ticket records and exports a 2,000-ticket expert-review queue.

### 4. Run Milestone 5

```powershell
python -m src.robust_training
```

Demonstrates label smoothing and cross-entropy using illustrative class probabilities.

### 5. Run Automated Tests

```powershell
python -m pytest -q
```

The current implementation contains 15 automated tests covering statistical calculations, review selection, and label smoothing.

## Reproducibility

The synthetic data generator and selection strategy use fixed random seeds so that repeated executions with the same inputs produce consistent results.

The source scripts are designed to run locally without GPU resources or access to external ML training datasets.

## Limitations

- The provided HelpDeskNet-50K scenario is fictional.
- No authentic ticket-level dataset was available.
- Synthetic model predictions do not demonstrate actual classifier performance.
- The 96.34% estimated accuracy depends on a simplified noise assumption.
- Label smoothing is demonstrated mathematically; no real classifier training was performed.
- Co-teaching is proposed but not experimentally implemented.
- Real-world model improvements would require authentic ticket records, expert-verified labels, and controlled training and evaluation experiments.
